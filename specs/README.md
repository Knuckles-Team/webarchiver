# webarchiver specifications

These specs follow the ecosystem [spec standard](https://github.com/Knuckles-Team/pipelines/blob/main/reference/spec-standard.md). One spec owns each capability. A contributor must extend an existing spec before a new one. Each spec uses one ID form, one title form and one file set.

## Owner

This repository owns the specs with the ID prefix `CONN-WEBARCHIVER`. The connector contract, certification, and transport rules belong to [agent-connector-sdk](https://github.com/Knuckles-Team/agent-connector-sdk/tree/main/specs).

## Local specifications

- [`CONN-WEBARCHIVER-WEB-SOURCE`](web-source/spec.md) — Web page fetch, extraction, render and screenshot connector.
